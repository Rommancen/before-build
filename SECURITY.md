# Security policy

Before Build is a documentation and decision-template repository. It does not run a service or process submitted customer data.

## Reporting a concern

Please do not publish secrets, personal data, client materials, or other sensitive information in a public issue or discussion.

For a security or privacy concern, contact the repository owner privately through [GitHub](https://github.com/Rommancen) and include only the minimum information needed to reproduce or assess the issue.

General documentation problems can be reported through the repository's issue templates.
